# ロバート・ケリー氏と語ろう会 お申し込みフォーム

2026年11月23日（月・祝）開催イベントの申し込みフォームです。
スマホで見やすい1ページのフォームで、申し込みは Google スプレッドシートに自動で記録されます。

## できること

- 入力 → 確認 → 完了 の3ステップで迷わず申し込める
- 参加する部（第一部／第二部／両方）・同伴者人数・会員区分・ご紹介者・メッセージ・次回案内希望を入力
- **残席の表示と定員管理**（同伴者も人数に含めて計算。満席の部は選べなくなる）
- **締切日時を過ぎると自動で受付終了**
- **自動返信メール**（日時・会場・地図・参加費・昼食持参などのご案内つき）
- 主催者への新規申込の通知メール（任意）
- 完了画面から **Googleカレンダー／カレンダーアプリに登録**、**会場の地図を開く**
- 全角で入力された電話番号・メールアドレスも自動で半角に変換

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | フォームのページ |
| `app.js` | フォームの動き（入力チェック・送信・カレンダー登録など） |
| `config.js` | **設定**（Apps Script のURL・締切・問い合わせ先） |
| `apps-script/Code.gs` | スプレッドシート側の受付プログラム（定員・メール文面など） |

## 公開までの手順

### 1. スプレッドシートと受付プログラムを用意する

1. [Google スプレッドシート](https://sheets.new) で新しいシートを作る（名前は例：「11/23 ケリー氏 申込一覧」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っているコードを全部消して、`apps-script/Code.gs` の中身を貼り付けて保存
4. 必要に応じて先頭の `CONFIG` を書き換える
   - `CAPACITY`：定員（初期値は第一部・第二部とも40名）
   - `DEADLINE`：締切（初期値は 11/22 23:59）
   - `ORGANIZER_EMAIL`：申し込みのたびに通知を受け取りたいメールアドレス
   - `CONTACT`：確認メールに載せるお問い合わせ先
5. 上部の関数選択で **`setup`** を選んで **実行** → 権限の確認画面で許可する
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」）
6. 右上の **デプロイ → 新しいデプロイ** →歯車から **ウェブアプリ** を選択
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. **デプロイ** を押し、表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー

### 2. フォームにURLを設定する

`config.js` の `GAS_URL` にコピーしたURLを貼り付けます。

```js
GAS_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

URLが空のままだと「デモモード」になり、画面上部に黄色い帯が出ます（送信しても保存されません）。

### 3. GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を **Deploy from a branch**、Branch を公開したいブランチ・`/ (root)` にして保存
3. 数分後に表示されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）がフォームのURLです
4. 一度自分でテスト申し込みをして、シートへの記録と確認メールを確認してください（テスト行は削除してOK）

## 運用のヒント

- **キャンセルが出たとき**：シートの「キャンセル」列に「済」など何か入力すると、その人数が残席に戻ります。
- **定員や締切を変えたいとき**：`Code.gs` の `CONFIG` を変更して保存 → **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**。締切を変えた場合は `config.js` の `DEADLINE` も合わせて変更してください。
- **確認メールの文面を変えたいとき**：`Code.gs` の `sendConfirmation_` を編集し、上と同じ手順で再デプロイします。
- 確認メールはスクリプトを作成した Google アカウントから送信されます（無料アカウントは1日100通まで）。
- 受付番号は `K001` から順に振られます。
